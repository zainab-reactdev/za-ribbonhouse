# ZA RibbonHouse 🎀

A single-page catalog website for **ZA RibbonHouse**, a handmade ribbon accessories business. Customers browse the collection and order directly on WhatsApp.

🌐 **Live:** [zaribbonhouse.netlify.app](https://za-ribbonhouse.netlify.app/)

## Features
- Animated hero with floating hearts and sparkles
- Product grid with an "Order on WhatsApp" button (message pre-filled with the product name)
- "Why Choose Us" section with custom line icons
- Our Story and Contact sections
- Mobile-first, responsive design

## Built With
React · Vite · Tailwind CSS · Netlify

## Run Locally
```bash
git clone https://github.com/zainab-reactdev/za-ribbonhouse.git
cd za-ribbonhouse
npm install
npm run dev
```

## Customize
Edit the constants and the `products` and `WHY` arrays at the top of `src/App.jsx`. Product photos go in `public/images/`.
